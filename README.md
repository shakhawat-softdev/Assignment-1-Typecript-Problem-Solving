# Assignment 1: TypeScript Problem Solving

This repository contains the solution files for a TypeScript problem-solving assignment. It includes TypeScript practice problems and two technical blog posts written in Markdown.

## Problems Covered in `solutions.ts`

The `solutions.ts` file includes solutions for the following TypeScript topics:

1. Filtering even numbers from an array
2. Reversing a string
3. Using union types with type checking
4. Accessing object properties safely with generics and `keyof`
5. Working with interfaces and object return types
6. Using classes and inheritance
7. Finding the intersection of two arrays

## Blog Posts

### Blog 1

**Title:** Why `any` Is a Type Safety Hole and Why `unknown` Is Safer

This blog explains:

- Why `any` can break TypeScript's type safety
- Why `unknown` is safer for unpredictable data
- How type narrowing works
- How to use type guards for safer code

### Blog 2

**Title:** How Generics Build Reusable and Strictly Typed Code in TypeScript

This blog explains:

- What generics are
- How generics improve reusability
- Generic functions and interfaces
- Generic constraints
- Practical examples of strictly typed reusable code
